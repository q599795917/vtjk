# vtjk

Vinted 店铺监控软件 —— 安装包分发与在线更新通道。

## 下载最新版

最新版本请见 [Releases](https://github.com/q599795917/vtjk/releases/latest)。

- 软件安装包：`VintedMonitor_Setup_vX.Y.Z.exe`
- 浏览器插件：`vinted-ext-vX.Y.Z.zip`

## 安装顺序

1. 先运行软件安装包，按提示装好软件。
2. 再按软件里的「插件安装」提示，把插件包装进浏览器。
3. 软件里点「检查更新」即可自动获取新版本。

## 说明

本仓库仅用于分发安装包与更新清单，不包含源码。
